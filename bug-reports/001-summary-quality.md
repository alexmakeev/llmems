# Bug #001: Summaries слишком сжатые и на неправильном языке

## Описание

При фоновой суммаризации (backgroundSummarize) создаются summaries, которые:

1. **Слишком краткие — теряются факты и детали**
   - Пример: разговор о праздновании Масленицы в разных странах мира (Италия, Франция, Германия, Бразилия, UK, Скандинавия, Польша, Чехия) с подробностями по каждой стране
   - Summary: "Alexander requests information on how Maslenitsa or similar pre-Lenten carnivals are celebrated around the world. The assistant provides a report detailing traditions in Italy (Venetian Carnival), France (Mardi Gras), Germany (Fasnacht), Brazil (Carnival in Rio), the UK (Pancake Day), Scandinavia/Baltic states, Poland, and the Czech Republic, highlighting common elements like costumes, food, and burning effigies."
   - Потеряно: все конкретные факты, традиции, детали по каждой стране. Summary описывает ЧТО обсуждалось, но не содержит СУТИ обсуждения

2. **Язык summary не совпадает с языком разговора**
   - Разговор велся на русском языке
   - Summary сгенерирован на английском
   - Summary должен быть на языке пользователя

## Ожидаемое поведение

- Summary должен содержать ключевые факты и детали, а не только "заголовок" темы
- Summary — это не заголовок, а сжатое но информативное изложение фактов. Должны сохраняться конкретные данные, числа, имена, выводы
- Язык summary должен совпадать с языком разговора

## Влияние

Когда пользователь возвращается к разговору после паузы (active chunks уже заархивированы), бот видит только summaries. Если summary — это просто "заголовок", бот не может:
- Продолжить разговор с контекстом
- Повторить действие по запросу "сделай ещё раз"
- Вспомнить конкретные факты из прошлого разговора

## Воспроизведение

1. Начать разговор с ботом на русском языке
2. Попросить подробное исследование (например, "как празднуют Масленицу в разных странах мира")
3. Подождать 10+ минут (backgroundDebounceMs = 600_000ms)
4. Фоновая суммаризация создаст closed mem
5. Проверить summary в таблице mems — будет краткий "заголовок" на английском вместо подробного изложения на русском

## Предложение по исправлению

- В промпте для LLM суммаризации (backgroundSummarize) уточнить что summary должен содержать ключевые факты и детали, а не только описание темы
- Добавить инструкцию: "Use the same language as the conversation"
- Увеличить допустимую длину summary (текущие summaries ~50-100 слов, нужно 200-400 слов для содержательных тем)
